# Few-shot примеры расширений

Выбрать один подходящий приём и читать указанные файлы, а не все решения.
Учебные исходники находятся в `examples/onec`, вне `v8project.yaml` и рабочего
каталога сценариев. Их наличие не требует сборки, загрузки или запуска тестов.
Выбор автоматизации новой задачи — по [триажу](../../onec-task-triage/SKILL.md).

## Что брать

| Приём | Точка входа | Дополнительно по необходимости |
| --- | --- | --- |
| Заимствование справочника и реквизитов | [АвтоАртикул](../../onec-extension-xml/samples/АвтоАртикул) | XML и обработчик объекта; подробности ниже |
| Собственный документ, статусы, проверки перед записью | [ЗадачаИТ.xml](../../../../examples/onec/ЗадачиИТ/source/Documents/ЗадачаИТ.xml), [модуль объекта](../../../../examples/onec/ЗадачиИТ/source/Documents/ЗадачаИТ/Ext/ObjectModule.bsl) | [Роль](../../../../examples/onec/ЗадачиИТ/source/Roles/РаботаСЗадачамиИТ/Ext/Rights.xml), [YAxUnit](../../../../examples/onec/ЗадачиИТ/source/CommonModules/ТестыЗадачИТ/Ext/Module.bsl) |
| Управляемая форма и отдельный серверный расчёт | [Модуль формы](../../../../examples/onec/Удвоение/source/DataProcessors/Удвоение/Forms/Форма/Ext/Form/Module.bsl), [модуль менеджера](../../../../examples/onec/Удвоение/source/DataProcessors/Удвоение/Ext/ManagerModule.bsl) | [XML формы](../../../../examples/onec/Удвоение/source/DataProcessors/Удвоение/Forms/Форма/Ext/Form.xml), [YAxUnit](../../../../examples/onec/Удвоение/source/CommonModules/ТестыУдвоения/Ext/Module.bsl) |
| Проведение, движения, остатки и возврат | [Модуль документа](../../../../examples/onec/НовыеМетаданные/source/Documents/НМ_ПередачаНаПроверкуБрака/Ext/ObjectModule.bsl), [серверная логика](../../../../examples/onec/НовыеМетаданные/source/CommonModules/НМ_ПроверкаБракаСервер/Ext/Module.bsl) | [Регистр накопления](../../../../examples/onec/НовыеМетаданные/source/AccumulationRegisters/НМ_ТоварыНаПроверкеБрака.xml), [YAxUnit](../../../../examples/onec/НовыеМетаданные/source/CommonModules/НМ_ТестыПроверкиБрака/Ext/Module.bsl) |

В `source` сохранён полный состав каждого из трёх расширений, чтобы можно было
найти зависимости выбранного объекта. Прежние бизнес-сценарии Vanessa удалены; для новой задачи создавать новый целевой сценарий.
Тестовые общие модули внутри исходников зависят от YAxUnit: не переносить их
в новую задачу автоматически. «НовыеМетаданные» читать только при необходимости
проведения/остатков; простому реквизиту этот пример не нужен.

## Границы проверки

Исходники и четыре feature-файла первоначально восстановлены 08.10.2026 из
[архива тренировок](setup.md#repository-cleanup); все 67 файлов побайтово
соответствовали SHA-256 его манифеста. Позже все бизнес-feature удалены по требованию очистки стенда. Повторной загрузки и исполнения исходников не было.

- **ЗадачиИТ:** журнал 06.10.2026 фиксирует 18 целевых серверных тестов и четыре
  успешных UI-сценария. Проверка роли не подтверждает работу ограниченного
  пользователя с профилем УТ. Архивный журнал — `docs/it-tasks-checks-20261006.md`.
- **НовыеМетаданные:** акт 06.10.2026 фиксирует 48 серверных тестов и один
  UI-сценарий. Акт в архиве — `docs/reports/defect-2026-10-06/acceptance.md`.
- **Удвоение:** пример поведения формы; в метаданных формы известно замечание
  `ExtendedPresentation`. При адаптации применить
  [правило XML формы](../../onec-extension-xml/SKILL.md#form-metadata),
  не копировать этот узел. Текущая загрузка исходников здесь не подтверждена.

Исторические результаты относятся к версиям описанных прогонов и не доказывают
приёмку восстановленных или адаптированных файлов сегодня. Бизнес-правила,
роли, зависимости и объём тестов брать из новой постановки.

## Минимальный образец заимствования

Дополнительный восстановленный пример —
[ЗапретДублейПартнеров](../../../../examples/onec/ЗапретДублейПартнеров/source):
поиск совпадающего имени и отказ записи у поля. Получен из коммита `2f969e6`
при [аудите Git](../../../../docs/git-audit-2026-10-08.md). Рядом сохранены исходные тесты,
но повторной проверки платформой не было; это материал для разбора, не эталон.
Тесты исторически размещались в `ТестыУТ`; в новой задаче адаптировать их
размещение и зависимости, не подключать весь прежний набор.

Для заимствованного справочника, реквизитов и обработчика объекта использовать
[АвтоАртикул](../../onec-extension-xml/samples/АвтоАртикул).
Рядом сохранён необязательный образец
[теста YAxUnit](../../onec-extension-xml/samples/ТестыАртикулов.bsl).
Он не включён в сборку. Старый сценарий Vanessa удалён.

Это фрагменты для адаптации, а не готовая поставка. Новые UUID, реальные имена
заимствованных объектов и совместимость проверять по
[XML-скиллу](../../onec-extension-xml/SKILL.md) и локальной выгрузке.
Для другого вида объекта брать XML из выгрузки платформы или подходящего
проверенного образца; не превращать справочник в документ заменой названия тега.

Остальные тренировочные решения, отчёты и генераторы остаются в
[локальном архиве](setup.md#repository-cleanup). Восстанавливать отдельный файл
только при необходимости; не подключать прежнюю регрессию к новой задаче.

`Коннектор` и `ПримальпОбувь` удалены из рабочего каталога при окончательной очистке;
копии сохранены в архиве аудита Git.

## Дополнительные ограничения образцов

- У АвтоАртикула реализация убирает ведущие нули числового кода (`00000000123` →
  `АРТ-123`), а соседние YAxUnit и Vanessa образцы ожидают исходный код. Перед
  адаптацией выбрать требуемый формат и согласовать ожидания; эти тесты не считать
  готовыми к зелёному прогону.
- В «НовыеМетаданные» блокировка всего регистра `ТоварыНаСкладах` ограничивает
  параллельную работу. Для новой задачи определить нужную область блокировки.
