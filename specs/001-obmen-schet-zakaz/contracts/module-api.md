# Контракт: программный интерфейс модулей расширений

Дата: 2026-11-08. Все функции — серверный контекст. Реализация новых модулей; существующие модули (ЭТШ_, ИТШ_, СШП_) не затрагиваются.

## ЭСВ_ЭкспортСчетов (bsp, расширение ЭкспортСчетовВШину)

```bsl
// Выгружает отмеченные счёта за период в топик Kafka порциями (по 100).
//
// Параметры:
//  Адрес     - Строка - адреса брокеров, например "localhost:9092"
//  Топик     - Строка - имя топика, например "invoices"
//  ДатаНачала, ДатаОкончания - Дата - период выборки счетов по дате документа
//  Отмеченные - Соответствие (необяз.) - ключ: Номер|ДатаISO, значение: Истина -
//             отмеченные в форме счёта; не задано - выгружаются все за период
//
// Возвращаемое значение:
//  Структура - Отправлено (Число), Ошибок (Число), Протокол (Массив строк)
Функция ВыгрузитьСчета(Знач Адрес, Знач Топик, Знач ДатаНачала, Знач ДатаОкончания, Знач Отмеченные = Неопределено) Экспорт
```

Внутренние правила: пропускает группы и счёта с `ПометкаУдаления` (строка протокола на каждый пропущенный); сообщение — по [invoice-message.md](invoice-message.md); исключение при недоступности брокера — наверх, форма показывает ошибку, ни одно сообщение не считается отправленным (частично отправленная порция фиксируется в протоколе).

## ИСШ_Шина (uf_demo, расширение ИмпортСчетовИзШины)

Копия паттерна `ИТШ_Шина` (топик/группа/имена макетов — `ИСШ_librdkafka_*`):

```bsl
Функция НовыйПолучатель(Знач Адрес, Знач Группа, Знач Топик) Экспорт   // KafkaConsumer
Функция ПрочитатьПул(Знач Получатель) Экспорт                          // Массив структур {Key, Value, Offset, Partition, Timestamp, Topic}
Процедура ЗафиксироватьСмещения(Знач Получатель) Экспорт               // Commit() — только после успешной порции
```

## ИСШ_ЗагрузкаСчетов (uf_demo)

```bsl
// Читает одну порцию сообщений и записывает заказы + эталон сверки.
// Офсеты коммитятся только если порция обработана без ошибок.
//
// Параметры:
//  Адрес, Группа, Топик - Строка
//
// Возвращаемое значение:
//  Структура - Прочитано, Создано, Обновлено, Пропущено, Ошибок (Числа),
//              Протокол (Массив строк "счёт: описание")
Функция ЗагрузитьСчета(Знач Адрес, Знач Группа, Знач Топик) Экспорт
```

Внутренние правила: разбор Value по [invoice-message.md](invoice-message.md); невалидный формат тела (неразбираемый JSON, отсутствие обязательных полей шапки) — счётчик Пропущено + запись в протокол, эталон не создаётся (не блокирует коммит порции); сопоставление по R-5; запись заказа и эталона `ИСШ_СчетаОбмена` — по R-7 и R-6 (эталон пишется для каждого разобранного сообщения, включая пропущенные по протоколу).

## ИСШ_СверкаЗаказов (uf_demo)

```bsl
// Сравнивает заказы приёмника с эталонами ИСШ_СчетаОбмена за период по дате счёта.
//
// Параметры:
//  ДатаНачала, ДатаОкончания - Дата - период сверки по ДатаСчета эталона
//
// Возвращаемое значение:
//  Структура - Проверено, Совпало, Расхождений (Числа), Отчет (Массив строк статусов)
Функция ВыполнитьСверку(Знач ДатаНачала, Знач ДатаОкончания) Экспорт
```

Статусы отчёта (по каждому эталону): `Совпадает`; `Документ отсутствует`; `Документ отсутствует (помечен на удаление)`; `Расхождение шапки: <реквизит>`; `Расхождение строк: <товар, поле>`; `Счёт помечен на удаление` (особый статус — шапка и строки не сравниваются, clarify Q8 раунда 2). Счёт без товарных строк пропускается загрузкой (спека, Edge Cases), эталон для него не создаётся — сверка по такому счёту невозможна.

## Формы (клиент)

- `ЭСВ_ВыгрузкаСчетов`: поля Адрес (по умолчанию `localhost:9092`), Топик (`invoices`), Период; динамический список счетов за период с колонкой-отметкой и признаком пометки удаления; кнопка «Выгрузить» → `ЭСВ_ЭкспортСчетов.ВыгрузитьСчета`, итоги и протокол — `Сообщить()`.
- `ИСШ_ЗагрузкаСчетов`: поля Адрес (`localhost:9092`), Группа (`uf-demo-invoices`), Топик (`invoices`); кнопка «Загрузить» → `ИСШ_ЗагрузкаСчетов.ЗагрузитьСчета`, итоги и протокол — `Сообщить()`.
- `ИСШ_СверкаЗаказов`: поля Период; кнопка «Сверить» → `ИСШ_СверкаЗаказов.ВыполнитьСверку`, статусы — `Сообщить()`.

Значения полей форм задаются как значения по умолчанию реквизитов формы (UI-прогоны Vanessa делают минимальное число шагов).
