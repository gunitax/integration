# Контракт: сообщение обмена счётом (Kafka)

Дата: 2026-11-08. Канал: топик Kafka (по умолчанию `invoices`), формат обёртки — как в обмене товарами (`{Headers, Key, Value}`).

## Обёртка

| Поле | Тип | Содержимое |
|------|-----|------------|
| Headers | Массив (JSON) | Пустой массив (резерв, как в ЭТШ) |
| Key | Строка | `<Номер>|<Дата в формате ISO>` — детерминированный идентификатор счёта |
| Value | Строка JSON | Тело счёта, схема ниже |

## Тело (Value)

```json
{
  "Номер":       "строка, номер счёта как есть (до 11 символов)",
  "Дата":        "строка ISO 8601, например \"2026-11-08T10:00:00\"",
  "Организация": {"Наименование": "строка (до 150)"},
  "Покупатель":  {"Наименование": "строка (до 50)"},
  "Валюта":      {"Код": "строка (до 3)", "Наименование": "строка (до 10)"},
  "Сумма":       число (Σ Сумма строк, 2 знака),
  "Товары": [
    {
      "Артикул":      "строка (до 25), может быть пустой",
      "Наименование": "строка (до 100)",
      "Штрихкод":     "строка, может быть пустой",
      "Количество":   число (источник 15,3; приёмник усекает до целого),
      "Цена":         число (неотрицательное),
      "Сумма":        число (неотрицательное)
    }
  ]
}
```

## Правила версии 1

1. Порядок полей в JSON не гарантируется; потребители читают по именам.
2. `Дата` парсится `XMLЗначение(Тип("Дата"), Строка)`.
3. Одно сообщение = один счёт; порядок строк `Товары` сохраняется из счёта.
4. Реквизиты, отсутствующие в схеме (Партнёр, характеристика, НДС, скидки, договор и пр.), приёмник игнорирует.
5. Обратная совместимость: добавление новых полей в Value — не ломающее изменение; изменение формата существующих полей — новая версия контракта (новый топик).

## Размеры полей приёмника (для сопоставления)

| Значение | Поле приёмника | Длина | Правило |
|----------|----------------|-------|---------|
| Организация.Наименование | Организации.Наименование | 25 | строгое полное |
| Покупатель.Наименование | Контрагенты.Наименование | 30 | строгое полное |
| Валюта.Код / Наименование | Валюты.Код (3) / Наименование | 25 | Код → Наименование |
| Товары.Артикул | Товары.Артикул | 15 | обрезка до 15 при поиске |
| Товары.Штрихкод | Товары.Штрихкод | 20 | обрезка до 20 при поиске |
| Товары.Наименование | Товары.Наименование | 50 | строгое полное |
| Номер | Заказ.Номер | 9 | обрезка до 9 + предупреждение |
| Количество | Товары.Количество | 10,0 | Цел() + предупреждение при дробном |
| Цена / Сумма | Товары.Цена/.Сумма, Заказ.Сумма | 10,2 | переполнение — протокол-ошибка |
