# Обмен товарами: БСП → Kafka-топик `goods` → uf_demo

## Контекст

Первый сквозной механизм интеграции проекта. Источник — `bsp` (БСП 3.1.12.348, товары = справочник `_ДемоНоменклатура`) с готовым расширением `СервиснаяШинаПредприятия` (СШП): Kafka через ВК librdkafka, продюсер `AddIn.librdkafka.KafkaProducer`. Приёмник — `uf_demo` («ДемонстрационноеПриложение» 8.5, целевой справочник `Товары`), Kafka-кода в нём нет. Правила: разработка только в новых расширениях, существующие модули не менять, UTF-8 BOM + CRLF, без «ё» в именах, SOLID/DRY/KISS.

Значения по умолчанию: брокер `localhost:9092`, топик `goods`, идентификация товара по Артикулу (при пустом — по Штрихкоду), перенос Наименование/Артикул/Штрихкод/Описание(Комментарий→Описание), запуск кнопкой в обработке.

## 1. Расширение `ЭТШ_ЭкспортТоваровВШину` (bsp)

`Q:\integration\bsp\src\extensions\ЭкспортТоваровВШину\` — AddOn, префикс `ЭТШ_`, совместимость 8.3.21 (как СШП). Файлы: Configuration.xml (новые uuid, DefaultRoles→ЭТШ_ОсновнаяРоль), Languages/Русский.xml (Adopted), Roles/ЭТШ_ОсновнаяРоль.xml, Subsystems/ЭТШ_ОбменТоварами.xml, CommonModules/ЭТШ_ЭкспортТоваров (+Ext/Module.bsl, серверный+внешнее подключение), DataProcessors/ЭТШ_ВыгрузкаТоваров (+форма).

Модуль `ЭТШ_ЭкспортТоваров.ВыгрузитьВсеТовары(Адрес, Топик)`: выборка элементов `_ДемоНоменклатура` (не группы, не помечены) → сообщения `СШП.КлиентСервер.Сообщение()` c Key=Артикул/GUID, Value=JSON{Артикул,Наименование,Штрихкод,Описание=Комментарий} → порциями по 100 через `СШП.СоздатьОтправителя()` → `Инициализировать` → `ОтправитьДанные` → `Уничтожить`. Форма: поля Адрес (`localhost:9092`), Топик (`goods`), команда «Выгрузить», итог сообщением.

## 2. Расширение `ИТШ_ИмпортТоваровИзШины` (uf_demo)

`Q:\integration\uf_demo\src\extensions\ИмпортТоваровИзШины\` — AddOn, префикс `ИТШ_`, совместимость 8.5.1. Файлы: Configuration.xml, Languages/Русский.xml, Roles/ИТШ_ОсновнаяРоль.xml, Subsystems/ИТШ_ОбменТоварами.xml, CommonTemplates/ИТШ_librdkafka_{win32,win64,linux32,linux64} (копии XML+Template.bin из СШП), CommonModules/ИТШ_Шина (серверная обёртка ВК-консьюмера: подключение по ТипПлатформы, `Новый("AddIn.librdkafka.KafkaConsumer")`, локальные `ПрочитатьJSON`; API: СоздатьПолучателя/ПрочитатьПул(без коммита)/Зафиксировать/Уничтожить), CommonModules/ИТШ_ЗагрузкаТоваров (разбор Value→JSON, поиск Товары по Артикулу/Штрихкоду запросом, СоздатьЭлемент/ПолучитьОбъект→Записать, Вид=Товар, обрезки длин 50/15/20; коммит только после успешной записи), DataProcessors/ИТШ_ЗагрузкаТоваров (+форма: Адрес, Группа, Топик, команда «Загрузить»).
